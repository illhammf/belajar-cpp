# 📚 Belajar C++ — Dari Dasar hingga OOP

Repository ini berisi perjalanan belajar **C++ dari dasar hingga Object-Oriented Programming (OOP)**.

Materi disusun secara bertahap agar dapat digunakan oleh siapa saja yang ingin mulai belajar C++, terutama untuk pemula yang belum memiliki banyak pengalaman dengan bahasa pemrograman.

Repository ini juga menjadi dokumentasi pembelajaran dan latihan saya dalam memahami fundamental C++ sebelum melanjutkan ke materi **Struktur Data**.

---

## 🎯 Tujuan Repository

Repository ini dibuat untuk:

- Mempelajari dasar-dasar bahasa C++.
- Memahami konsep pemrograman secara bertahap.
- Membiasakan diri menulis kode C++.
- Mendokumentasikan proses belajar.
- Menyediakan referensi sederhana untuk pemula.
- Membangun pondasi sebelum mempelajari Struktur Data.
- Mengenal konsep Object-Oriented Programming.

# 💻 Menjalankan Program

Setiap folder memiliki beberapa file `.cpp`.

Contoh:

```text
pertemuan-01/
└── 01_hello_world.cpp
```

Compile menggunakan:

```bash
g++ 01_hello_world.cpp -o program
```

Kemudian jalankan:

### Windows

```bash
program.exe
```

### Linux / macOS

```bash
./program
```

> Nama file executable dapat disesuaikan dengan kebutuhan.

# 🤝 Untuk Pemula

Jika kamu baru belajar C++, jangan langsung mencoba memahami semua materi sekaligus.

Disarankan mengikuti urutan:

```text
Pertemuan 01
      ↓
Pertemuan 02
      ↓
Pertemuan 03
      ↓
...
      ↓
Pertemuan 13
```

Setiap pertemuan memiliki contoh kode yang dapat dijalankan dan dipelajari satu per satu.

Cobalah mengubah kode yang tersedia.

Misalnya:

```cpp
int umur = 20;
```

ubah menjadi:

```cpp
int umur = 25;
```

Kemudian lihat apa yang terjadi.

Eksperimen kecil seperti ini sangat membantu dalam memahami programming.
