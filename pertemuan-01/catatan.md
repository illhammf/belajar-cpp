# 1. Apa Itu C++?

C++ adalah bahasa pemrograman general-purpose yang dikembangkan sebagai pengembangan dari bahasa C.

C++ mendukung berbagai gaya pemrograman, seperti:

- Procedural Programming
- Object-Oriented Programming
- Generic Programming

C++ banyak digunakan untuk berbagai kebutuhan, seperti:

- Software
- Game Development
- System Programming
- Embedded System
- Desktop Application
- Competitive Programming
- Data Structure & Algorithm

# 2. Hubungan C dengan C++

C++ memiliki sejarah yang sangat dekat dengan C.

Secara sederhana:

```text
C
│
├── Fundamental Programming
├── Procedural Programming
├── Pointer
├── Memory Management
└── Struct
       │
       ▼
      C++
       │
       ├── Object-Oriented Programming
       ├── Class
       ├── Object
       ├── Reference
       ├── Template
       ├── STL
       └── Generic Programming
